# 雨雪

适用于侧视雨幕、稀疏飘雪与暴雪中的可辨识雪片。先决定观众应感到湿冷、疾速、轻柔还是压迫，再决定近远层；密度和大小不是同一件事。雨的主体是方向稳定的长条，雪的主体是慢速、有形状差异的点片。远处小粒子提供空间，近处大粒子提供速度参照，不能把全部粒子同时放大。

Unity rainSimple 用两种雨条与两组地表水纹，雨寿命0.4–0.5秒、垂直速度约80–100单位/秒，水纹寿命3–5秒。该例雨 renderer 是垂直 billboard，不是速度拉伸；雨条形状由 rain-s3 与 rain2-s3 素材承担。snowflakes 用三种静态雪花、低初速、慢旋转和透明度包络；单体 snowflake 则是0.25秒长大消失的装饰闪现，不能直接当持续降雪。

二维先把出生区放到画面上缘，速度指向下方，按素材前向轴选择 fixed 或 velocity alignment。雨长宽比例由真实长条素材或 startScaleAspect 提供，旋转只改变方向，不增加长度。没有动态伸长字段，固定长条不能承诺随速度实时变长。雪以 normal 混合保留剪影，雨可按素材选择 add 或 normal，亮度由背景决定。静态雪花用 random 出生定帧；只有连续演变的雪片图集才用 sequence。地面水纹可以独立安排发射，但不是雨滴碰撞触发。

建议例：假设画面高600逻辑单位、已具备透明雨条，近雨速度600–750单位/秒、寿命0.9–1.1秒，远雨速度250–350、尺寸为近雨的0.45倍；长宽比先取8:1，先预览再调整。出生区高度与寿命应覆盖画面，N≈发射率×平均寿命用于控制同时可见数量。可用近雨、远雨、水纹三个职责压缩，也可只做单层细雨；合并水纹会丢失落地反馈。三维碰撞、地形遮挡、视角深度与风噪声不能由增加数量补偿。舒适密度、前景遮挡与雨雪质感均是艺术目标，只记录偏差供用户审阅。
