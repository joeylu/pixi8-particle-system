# 局部电弧与放电

适用于固定区域内的短电弧、物体周围的断续放电和余亮屑。电的识别来自折线、分叉、瞬时强亮与断续节奏；空间位置由该次局部事件给定。

Unity electricity 基础组件使用8×8 electric图集、零速、零时刻单粒子、寿命0.125–0.2秒，形态变化主要来自UV动画。lightning-3D将同一8×8雷纹叠在三个mesh系统，寿命0.25–0.5秒，用空间朝向增加体积。二维可压成清晰的固定观看面轮廓，代价是失去绕物空间与视差；这不提供程序分叉或真实光照。

主体不必已有整幅放射图。实际库若提供静态分叉弧，可在中心区域用少量不同角度单元交叉，配合两三次分段出生近似多向放电。静态弧的角度与出生变体只改变整体现形，不是内部电流动画；只有观察到折线连续演变的帧才用sequence。无关弧形变体用random，不按文件列表串播。

静止主弧用fixed，保持素材长宽比与构图；余辉可用较大、较弱同形图，短闪光承担峰值，亮屑承担余量。主弧常用add但需检查白化，不把烟或暗边一律add。序列时长N/fps，短寿命会截断、长寿命会停留末帧；循环背景可随机相位，单次局部放电从首帧开始。

建议例（设计估算）：12帧完整局部放电、宽80逻辑单位，主弧0.2秒、fps60、t0 burst1；t0.04再出生一枚0.12秒弱弧，核闪0.06秒，余辉0.18秒，外散点0.3秒。保留主弧、短闪、亮屑三个职责即可；同轮廓余辉可烘焙进主弧序列，损失独立亮度控制。没有连续帧时只承诺断续显隐；不以提高fps填补内部动画。最终检查局部构图、负空间与峰值是否仍可读。
