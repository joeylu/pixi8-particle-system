# 闪光与光晕

适用于命中亮点、镜头耀斑、短促法术闪光、温和持续光晕。先区分光源的可读核心、外圈软光和放射形状；亮并不等于整屏变白。锐利形状提供方向和瞬时力度，软边提供扩散，较长残光帮助观众读懂位置。

Unity megaflare 把 lensflares、glow、电、烟、sphere base、twinkle、ray、base pulse、base glow 分开；其中base pulse寿命0.5秒、尺寸6，base glow寿命0.8秒、尺寸8。基础lensFlare只用静止单粒子、0.25秒寿命、尺寸2、零时刻burst1，大小从0长大，颜色/透明度调出显隐。复杂闪光里的烟与电各有动画职责，并非每个光晕都要复制。源作材质同时有add与alpha，不能把全部明亮部分都改成add。

二维按锐核、光圈、软晕、可选射线拆分，fixed保持构图，缓慢z旋转仅用于已有放射纹理。纹理静态时用single；多个静态耀斑形状用random池；只有光形真实变化的图集才sequence。核心与晕的尺度关系比绝对尺寸更重要：核心应可辨，晕更大更弱；alphaCurve让峰值先到，scaleCurve让扩散晚到，避免同步放大导致“气球感”。add可用于发光纹理，但先确认其alpha编码和背景表现；normal适合需保留实体明暗的纹理，软边并不决定blend；提高alpha也不会生成真实灯光。

建议例：假设可用白核、软晕、射线三张透明图，闪核宽24逻辑单位、寿命0.08秒，晕宽120、寿命0.35秒，射线宽180、寿命0.12秒；同刻burst，核立即到峰，晕在归一化年龄0.15到峰后衰减。峰值和面积先预览，白色吞掉细节时减晕的alpha或数量。megaflare九个视觉系统可按职责压为锐核、软晕、环、射线、电、烟六层；合并两类glow会减少独立残留时间，删除烟会减弱实体体积感。简单闪光一层即可。真实曝光、bloom、照亮场景和屏幕镜头效应不属于当前粒子能力，增大光图只是平面近似。明暗层次、舒适度和光感为艺术目标，偏差不阻断可运行交付。
