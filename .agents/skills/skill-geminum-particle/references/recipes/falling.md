# 落叶与碎屑飘落

适用于树叶飘落、受扰后扬起再落下的叶片、缓慢轻碎屑。先区分持续环境与一次受力：前者要保持稀疏节奏和可辨认叶形，后者要让起势、失速、下降构成一个动作。叶片旋转不应掩盖重心运动；尺寸过小只剩噪点，过密则像雪。

Unity loop_leaves 同时使用三类静态叶图、billboard 与 mesh 分支，带碰撞、向上速度及向下力，另叠加8×8烟动画和细颗粒。某叶层初始速度0.125–0.3125、额外向上速度1.25–1.5625、向下力1.5625，约0.8–1秒后由上升转下降。leaf-dampBurst 则在零时刻发5–8片，初速4–5、寿命0.75–1.25秒，再用限速模块衰减。这两个例子分别说明“起扬后落下”和“快喷后缓下来”，不能把同一低速下落配方用于全部碎屑。

二维保留大叶、中小叶、可选薄尘的职责；同一尺寸、寿命、混合与运动语义的叶形可合并为 random 池，节省层数但失去独立叶种节奏。叶片用 normal，fixed alignment 配合 rotationOverLifetime.z；只有细碎屑确实要顺速度伸向时才选 velocity。恒加速度可做抛落，drag 可做平滑失速，但不能把Unity dampen值直接当drag。纹理若只有正面，平面旋转无法产生翻面、侧缘和受光变化；真正翻转需要已存在的连续帧，用 sequence 而非随机帧跳换。

建议例：假设叶宽18–30逻辑单位、侧视受扰起扬，出生速度80–120单位/秒朝上，向下加速度160–220单位/秒²、寿命1.6–2.4秒，z转速范围−1到1 rad/s；8片burst配合较少持续小叶。起扬时间约v/a，先确保顶点高度适合场景再增粒子。可压成主叶、细叶、薄尘三个职责，也可只交付主叶；压掉薄尘会减弱空气受扰感。无碰撞时叶片不会落地停留，无噪声时轨迹不会来回扑动，无三维mesh时不会真实翻面；这些缺口需说明，不能以旋转或随机尺寸假称已实现。轻盈、自然和节奏差异是人工视觉判断。
