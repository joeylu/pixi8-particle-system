# 爆炸

用于瞬间能量释放、炸弹、火球爆开。先看材料是否已包含亮核与烟滚散；完整序列可以独占一层，不按帧数拆层，不强制烟、冲击环和碎片都出现。

原作证据：`Prefabs/Oneshot/pf_vfx-ult_demo_psys_oneshot_realisticExplosion.prefab`，198666781967075222/L4694，burst1、life2s、size4、speed0，realisticExplosion.png按8×8全表播一次。基础 `Expansions/XP - CONSTR. KIT/Prefabs/Oneshot/Explosions/pf_vfx-ult_xp-ckit_psys_oneshot_realisticExplosion.prefab`，198561624007228386/L44，同样单粒子序列，但尺寸在年龄0/.25/1处为.25/.95/1、帧终点.95。区别在展开节奏，不能机械套相同曲线。源码路径只审计，不绑定运行资源。

二维保留爆开的瞬间、核心扩张和长尾消散。可将职责分成主体、短闪、飞散点、薄烟；需用的才分层，总计≤8。主体全序列由真实clips驱动；若N帧需播放T秒，fps=N/T。光闪尺度建议主体的.6..1倍、烟尾1..1.5倍，闪最短、烟最晚排空。烟normal；亮核可add，但整张含暗烟的图用add可能丢烟，需观察alpha和背景。

建议例子，非原样复刻：主序列寿命.8s、t0 burst1、startSpeed0；假设真实clip有24帧，fps30，scaleCurve为(0,.35),(.2,1),(1,1.1)。独立短闪寿命.10s，碎点寿命.3.. .6s、t0 burst12、平面outward，最后烟寿命1.2s。逻辑尺寸从实际图可见包围框换算，不能把Unity size4直接当像素。

使用静态材料时先区分完整爆炸与局部火团。已有放射瓣、爆心、烟尾的完整图保留整体轮廓；外围外扩只添加真正局部且相容的团块，避免同一个完整轮廓在中心重复形成花瓣或蜂窝。静态随机池改变外观选择，不产生内部翻滚；完整动作序列经观察确认后优先由动画承担展开，避免重复做尺寸扩张。

缺内部翻滚序列时，交付与材料职责相符的静态主体和可用飞散层并记录动画缺口；缺烟贴图时保留已有主体，不造ID。省真实灯光、景深和折射会减弱体积/受光，六七成识别度仅为艺术目标。曲线2..8点，末端必须覆盖t1；Unity切线与非匀速取帧只做近似说明。
