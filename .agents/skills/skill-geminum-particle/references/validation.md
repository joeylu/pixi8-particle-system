# 校验

## 最终阻断

只阻断确定不能交付的错误：JSON/Schema 结构非法、运行构造或数值计算必然失败、纹理/帧引用非法、超过 8 层。检查范围次序、有效索引、共享 Source、发射窗口和实际容量/出生预算等运行前提。服务端或 SDK 提供准确错误路径，不把视觉偏好扩成硬条件。

有真实资源的可运行配置允许交付。缺素材只交付实际存在的层，附 warning/gaps 和纹理 brief；没有任何可用层才失败。不得为了通过检查创造占位资源。

## 设计提醒

角色缺失、blend 偏好差异、随机/动画设计差异、动画未完整播放、密度/范围偏差以及 preserve 偏差均为 warning，不触发模型重试。明确具体偏差和用户可调参数，不用主观评分阈值决定保存。

无画面时标明未渲染，不能把 JSON 通过称为视觉通过。实际画面评审需要用户请求或开发验收提供真实图像；观察出现、峰值、发展、结束及背景可读性、边框接缝、重复同步、曝光和突变。不新增生产渲染模型关口。

## 一次修复

最终配置首次有可修正的致命错误时，同一配置阶段读取原输入、首次输出和具体 fatal issues，只修配置一次。warning 不修复；不重选图、不重规划、不扩大目标。最多两次生成与最终校验，续跑不重置预算。网络、鉴权或模型执行失败不伪装成配置修复。

第二次仍失败则停止并报错，走 failed/waived、0 credit；用户可取消/清理失败任务，不走收费的产物 discarded 路径。技能不自行调用计费或取消接口，执行由宿主服务负责。
