# 移动电能弹

这是带电亮头、局部电纹和后方残留的移动弹体；没有两个精确端点之间的持续电弧。电纹应围绕头部出现，尾部间歇闪烁且迅速衰减，不能画成长时间贯通屏幕的直线束。

5–6 层：局部窄白蓝核、局部短电纹贴片、局部弱光晕、世界断续电残影、世界稀星点、可选透明薄烟。电纹使用可辨认折线轮廓与方向随机，尾贴片沿宿主速度排列，保留间隙；烟不可盖住尖锐电纹。压缩多个沿途子系统会丢失独立随机节奏；三维电纹贴片的朝向与 mesh trail 不能原样移植。

纹理需要短折线电纹变体、streak 核、soft glow和点纹理；电纹静态随机选帧与真正时间序列必须分开。若仅两格独立折线，就固定/随机选一格，不能宣称连续放电动画。PFX_Particles.shader L26 的 Blend 属性与材质保存值确定加色或透明，不能从蓝色或名称判断。使用自有或授权素材，不复制原图。
