# 喷口热流与烟尾

这是尾流资产，主体是喷口附近的短热流与滞后的烟；不包含自带弹头或飞行器。需要机体时由外部宿主提供位置、方向和移动，喷口朝运动反方向。静止喷口仍可排气，不能用整体平移伪造烟尾。

证据：`C:/Unity/Donut/Assets/QFX/ProjectilesFX/VFX_Prefabs/Projectiles_Particles/VFX_Ares_Projectile_Only.prefab` L35 fileID `302430584` 和 L28853 fileID `7235227743657216974` 两个 Smoke_Along 启用 5×5 UV；L4797 fileID `159354208766635791` 是火星；L19272 fileID `5100373746133195175` 为 Glow。此配方只借用尾部构造，不携带该 Prefab 主弹速度与碰撞逻辑。

使用 4 层，必要时最多 6 层：局部空间喷口白黄亮点、局部短橙热流、世界空间褐烟、世界空间灰烟；可加世界零星火屑和局部柔光。热流有窄根与外扩尖端，寿命短；烟离口后扩张、减透明，沿历史位置留存。两烟分别承担热烟与冷烟，预算紧时合并会丢失温度梯度和前后节奏。三维锥形投影为二维扇形，损失背面粒子遮挡。

需要热焰轮廓、柔烟时间序列、细火星，不能拿 glow 图代替所有层。源 5×5 UV 只说明帧网格，具体顺序读取 frameOverTime/startFrame；新图集需声明行列、时间帧语义和帧间轮廓连续性。烟用透明混合，热光可加色，但依据材质属性确认；PFX_Particles.shader L26 参数化 Blend、L127–128 主纹理采样。来源需自有或授权，不复制原纹理。

二维估计：喷口宽 10px，热流长 32px、寿命 .08–.18s，烟 .5–1.1s，烟尺寸 12→48px，喷烟 rate 25/s。速度与画面尺度会改变尾密度；没有距离发射、noise 或 tile 模式，只能宿主移动+时间发射。停机后立刻停止热口与新增烟，世界烟自然消散，不能把已存在烟拖回机体。

材质完整性：Ares/MFX_Trail_2.mat 使用 noise 主图+FX_Mask_1 红通道，PFX_Trail.shader L144–165 双速滚动后乘 mask；原始 noise 不能当完整 trail。此运行器用自有素材烘焙最终渐细轮廓/序列，或明确静态近似并接受滚动层次损失。RGB 黑底图可在加色下有效，透明混合则需正确遮罩；保存贴图槽只在 shader 实际采样时才生效。
