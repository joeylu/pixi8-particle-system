# 持续镭射与直束

用于源端与目标端同时可见的照射束身，不用于只有一截亮头飞过去的能量弹。Ultimate VFX 的 `Prefabs/Loop/pf_vfx-ult_demo_psys_loop_laserbeams.prefab` 每侧七系统，fire（fileID 19883510）与 shards（19883518）为 stretched billboard，lensflare、points 等补亮度与细节；无脚本端点绑定、无启用 Trail。这提供核心／外围差异的参考，不是现成两端梁。

压为细明核、较宽软束、可选局部流动序列三职责；端点 flash／impact 独立。多种光粒合并损失纹理丰富度，却应保住细核比外晕清晰和束身全长连贯。全部沿 local +X，静止粒子、fixed、add 常成立；材质若本身含明亮软边，不必再叠光晕。单帧可表现稳态梁，内部能流须有真实序列，随机不同形状的电弧不能冒充平顺流动。

二维建议例（非原值）：基准长度240、明核宽4、晕宽14，0秒各burst1，演示持续 .8s；核心alpha .85、外晕 .2，结束由宿主清头式 stop 清除束层。按实际图可见长宽换算 startScaleAspect，不能直接用240作为倍率。宿主根据两端只缩放束长，端点效果不被拉伸。零长停止／隐藏，不使用零scale空间变换。

现有 Sprite 伸缩会拉长图中纹理细节，不实现距离平铺、折线噪声、光照／HDR或弯曲束；材质的流动若来自 Shader，需要烘焙图或记录静态损失。缺少长条材料时，分散小光点通常不能提供同样连续束身，应说明缺口。
