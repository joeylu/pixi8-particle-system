# 二维构建逻辑

## 头、喷口与世界余留

外部飞行物驱动 emitter；local 静止头部和短火舌随它平移、转向，world 烟粒在出生位置留下并继续自己的低速漂移。喷口逆飞行方向喷出热流，与整个源前进不同。先选移动主轴（通常 local +X），再将源素材轴旋转到它；local 零速头部的 renderer.alignment="velocity" 不能读出宿主速度。

不是所有尾巴都用 Trails：独立烟团、火星、图形碎片用时间发射形成离散世界残留；连续窄光带才考虑 worldSpace trail。统一降低 alpha 不能把一团重复完整图变成流动尾焰。合并源作的多烟／多星层时保留长短寿命及宽窄对比，不照抄 3D 层数。

## 尾迹职责与层数

根据效果身份选择有贡献的对比：内尾可以窄、亮、短，连接主体和运动方向；外尾可以宽、柔、长，形成体积与历史轮廓；碎尾可以稀疏、断续、略偏离主轴，留下星屑、火丝或碎片。烟是有遮挡感的介质余留，不能自动当作发光外尾。它们是可选职责，不是每种效果必备的三层模板。

先判断单一材料/行为能否同时表达目标。已有明核软边的好素材可独立成立；需要不同长度、寿命或运动时，用不同配置层表达。可以复用同一纹理，但要在宽度、存留、发射分布或连续/破碎形态上有实际差别；复制相同尾层只改颜色或数量通常只是变亮。已有星屑层承担碎尾时直接复用，不能重复加一层凑类别。

每项职责分别选择实现：方向合适的单帧可映射到现有Trails；局部短焰可随头；柔光、烟与碎屑可在world留下。多个职责可以混用这些方式，“多层尾迹”不代表新增多带Trails模块。单层的body与trail已有配对关系，按真实layers数量计预算；叠加后的总亮度、粒子与Mesh成本一起估算，不因尚有空余层就填满8层。

## 速度、间距和寿命

已知宿主速度 v、想要平均间距 d，可估 rateOverTime≈v/d；留存时长 T 的尾长量级 L≈vT，人口≈rate×平均寿命。这是恒速与足够宿主采样下的近似，不是 rateOverDistance 能力。变速、低帧率、转急弯时重新检查空洞和扎堆；不能只增发射率掩盖全部粒子在一帧末位置出生的问题。

头部存活时间应覆盖有依据的最长飞行时间，并由实际结束事件提前终止；不要拿数百秒寿命掩盖缺少宿主约定。当前 trails.lifetime 乘的是头粒子的总寿命，不是当前年龄，也不是秒：头寿命 2s、希望点保留 .25s，倍率约 .125。改头寿命后同时核对尾长。maxPointsPerTrail 和 minVertexDistance 限制轨迹分辨率及有效长度，单次位移超 breakDistance 会断段。

## 束线与飞行光条

持续束线同时连接源端与目标端；飞行光条在某一时刻只有局部弹头和短尾。现 JSON 没有两端绑定或程序线几何。首轮直束可以将仅含束身的 local 配置按已知基准长度设计，由宿主平移到两点中点、旋转到连线方向、只沿长度轴缩放。端点火花／命中放独立效果，否则跟着束身被拉长。零长时宿主停止或隐藏束身，不传入不可逆的零缩放空间变换。

该近似只适合固定横向轮廓的直条；不保证图像中的分叉点、装饰圆环在伸缩后仍正确。stretch 不等于 tile，固定局部弯线也不等于能按任意路径弯曲。需要精确动态弯束、噪声拓扑或纹理循环流动而没有对应能力时，记录缺口或使用真实烘焙序列，不能发明配置字段。

## 3D 与 Shader 的取舍

先读 Transform 与前向轴，再将平面投影定到宿主 XY；原作 XZ 平射不是把 Z 扔掉。3D Mesh 的箭、冰片、刀弧、旋风用匹配侧视轮廓或动画承接，单张 UV 展开图通常不能直接当 Sprite。Z 散布可转为有限大小／速度／alpha 的变化，但不要声称有真实深度遮挡。

Shader 滚动、噪声扭曲、遮罩溶解、渐变映射及 Bloom 可能承担主要形态，单纯 base texture 不代表最终材质。优先已烘焙的正确外观；其次明确采用静态轮廓＋出生随机＋渐消的近似，并说明损失。保持热核、透明余焰和暗烟的面积／明度关系；发光可用 add，遮挡性烟／实体碎片通常 normal，实际素材编码和背景决定可用性。

## 命中与组合

flash→flight→impact 是事件关系，不是三个位置共享一条时间轴就自动完成。命中时停止所有未来发射，清除应消失的头层，既有 world 烟及允许保留的尾迹继续 drain。impact 对齐实际接触位置／法线，既有尾迹不搬过去。局部飞行表现、运动控制、碰撞判定分别有明确所有者。
