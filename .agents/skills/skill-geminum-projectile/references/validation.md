# 校验与预览边界

共享效果 Schema、实际 SDK 构造和资源引用决定最终结构校验。只阻断确定不可运行的 JSON、非法数值关系／引用、超过 8 层等错误；首次可修的致命配置错误返回具体路径修一次，第二次仍失败即停止。warning 不触发重规划、重选图或额外模型循环。

材料用途、头尾比例、颜色／blend 偏好、源作层数损失、间距近似和未完整播放的动画都作具体 warning，不用主观评分拒绝可用效果。独立工作保留错误及已有产物；服务的取消、积分返还按它的现行合同处理，本技能不自行调用接口。

开发预览优先检验：起步头部已出现；直线和转弯时 local 头与 world 余留各在正确空间；停止／提前命中立即清头且余烟、余尾按策略留下；世界尾迹没有被带回出生点；正反方向没有镜像／前向轴错误；加色没有吞掉关键轮廓。带状尾检查首尾朝向、转弯接缝和断段，直束检查两端变化与零长处理。只测需要的路径，不为每种艺术方案新增生产审阅关口。

没有实际帧或 GPU 绘制证据就标明未渲染；解析／类型测试通过不等于画面通过。真实纹理或宿主适配尚未提供时说明限制，不用测试占位图证明素材检索或最终视觉已经成功。

核对并列 projectile 元数据：mode 与实际运动所有者一致；killLayerIds 只指向真实层；beam 模式具正 referenceLength 与二元 referenceCenter，其他模式无 beam。致命修复时同时更新配置与元数据，仍只修一次；视觉 warning 不重试。
