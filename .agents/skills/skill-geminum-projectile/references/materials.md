# 素材观察与适配

读取设计、真实候选图／帧页和可用元数据，不根据名字或源包样式替素材补画不存在的东西。记录候选身份、textureSet、页与 ordinal、观察证据及不确定性。材料实际宽高、resolution、亮核／可见边界、前向轴和首尾布局直接影响 scale 与放置。

先辨认用途：完整弹体、可拼装的局部火舌、连续 ribbon、短速度条、烟团、独立冰片，还是仅 Shader 输入的 noise／mask／ramp。图集中多个无关图案是随机静态变体，不是动画；缺少时间顺序证据不排列播放。连续动作允许多个 clip，但 clips 只引用看过且确认的 ordinal。

按设计的尾部职责判断材料覆盖：内尾需要可读亮核，外尾需要柔边与低对比层次，碎尾需要独立细节。逐项说明一张图已包含什么、哪些职责能共用、哪些需要补充；不要求每项都找新图。硬实芯胶囊可作短亮段，但不能仅凭同图放大就称为柔外尾；若缺少柔边材料，记录会出现条带或硬边的近似，不悄悄删除设计要求的宽窄/连续性对比。

尾带的长度轴与 renderer UV 映射需要核对。当前 trail 沿路径长度从 u=0 到 u=1，横向 v 覆盖宽度，固定 stretch；如果尖尾在错误一端，不能靠 forwardAngle 反转 trail UV。选择方向合适的图、通过已授权素材加工获得正确图，或明确缺图。尖尾／淡尾可烘焙在图中，透明度突删与柔和渐消仍要看真实预览。

选材可依赖的Trails能力只有恒宽几何、全带统一tint/alpha、stretch和点TTL；没有沿尾宽度曲线、逐点年龄透明曲线或UV反转参数。对称光条不能靠这些不存在的参数变成尖尾。普通world粒子可用自身尺寸/颜色/透明曲线形成离散渐变尾，需另行判断接缝与密度；将此写为配置适配候选，不冒充连续尾带已经满足需求。

每 textureSet 内帧需要共享真实 TextureSource；两张独立 PNG 不自动属于同一 Source。同一 atlas 中的不同局部帧可以组成显式 textures 池；无 atlas 打包能力时，分到独立层并重新核算 8 层。Trail 仅使用单帧、无 trim/rotate 的合规图。相邻格的边框、图集留白及不完整的长条末端都要真实观察。

黑底 RGB 的光图在正确 add 混合下可能可用，不统一要求 alpha。normal 的烟和实体需要可用透明编码。QFX 某些 trail 材质将 noise 与 mask 相乘；Master 的轮廓可能来自 Mesh＋ShaderGraph，而不是 base texture 本身。原材质存在纹理槽不表示该槽实际被 Shader 使用，也不表示当前 runtime 支持同样合成。

没有理想长尾时，可用短局部残影或离散世界粒子承接部分速度感，说明连续性损失；没有明确头部形状时，不用泛化光点声称已完成箭矢／冰锥。材料缺口给出生成 brief（轮廓、侧视、朝向、首尾、透明方式、静态或动画），保留实际可交付角色。不要把这些艺术偏差升级成生产阻断。

同一真实 texture 可跨层、跨职责复用，参数各自独立。共用候选须先真实观察，再按每项职责分别判断形态、帧语义、方向、亮度与可补偿范围；一种职责适配不代表其他职责自动适配。
